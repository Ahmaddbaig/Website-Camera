Hardware Overview

The parts and software behind the Sentry camera, built as a student project.

Control Unit

  • Raspberry Pi as the main controller
  • SD card for recorded footage
  • Controlled over SSH from a desktop

Camera and Motion

  • Adafruit camera module
  • Servo motors for pan and tilt, with 180-degree rotation
  • PCA9685 servo driver

Software

  • Python on the Raspberry Pi
  • Flask web app for the live feed and controls
  • YOLO object detection, converted to NCNN for speed
  • HTML, CSS and JavaScript front end
